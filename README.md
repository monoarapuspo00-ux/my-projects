 # Healthcare Portal (Core PHP)

A smart, all-in-one healthcare web platform that connects patients to the right care —
built entirely with Core PHP and MySQL.

## 🌟 Unique Features

- **Symptom-Based Smart Suggestion** — Patient selects one or more symptoms, and the
  system automatically matches the relevant medical department, recommends suitable
  doctors, and suggests which diagnostic tests may be needed.

- **Direct Doctor Appointment Booking** — Patients can book an appointment with a
  chosen doctor by selecting date, time and hospital, with instant email confirmation.

- **Medical Test Price Comparison** — Search any test (e.g. Blood Test, X-Ray) and
  instantly compare its price across multiple hospitals to find the most affordable option.

- **24/7 Pharmacy Locator** — Find pharmacies that are open right now, including
  ones open 24 hours, shown on an interactive map.

- **Nearby Hospital Finder** — Locate the nearest hospitals based on the patient's location.

- **Transport Booking** — Book transport/ambulance service directly for hospital visits.

- **Admin Dashboard** — Full backend to manage doctors, hospitals, departments,
  pharmacies, tests, and appointments.

## 🛠️ Technologies Used
Core PHP, MySQL, HTML, CSS, JavaScript

## 📌 Why This Project Is Different
Unlike a typical CRUD-based hospital management system, this platform focuses on
**guiding the patient from symptom to solution** — suggesting the right doctor and
test based on symptoms, comparing test prices across hospitals, and arranging
transport — all in one workflow.
